# BuddhasPalm Android Apps

Android source for the Buddhas Palm Admin and Provider applications.

- `BuddhasPalmAdmin` → https://metro.buddhaspinas.com/admin/
- `BuddhasPalmProvider` → https://metro.buddhaspinas.com/provider/

Both apps use the same live Buddhas Palm backend and database, with separate Android package IDs and login sessions.

Build artifacts are generated by GitHub Actions from `.github/workflows/build-apks.yml`.
