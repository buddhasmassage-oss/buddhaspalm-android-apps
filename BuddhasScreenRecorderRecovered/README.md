# Buddhas Screen Recorder Android

Recovered/rebuilt Android source from the existing Buddhas Screen Recorder v1.3.0 APK behavior and package contract.

- Package: `net.buddhaspinas.screenrecorder`
- Website: `https://screenrecord.buddhaspinas.com/`
- Native whole-screen MP4 capture with optional microphone
- Floating recorder ball
- Local recordings in `Movies/Buddhas Screen Recorder`
- WebView bridge for the website/PWA

## Branding update
All visible app branding and the floating recorder ball use the uploaded Buddha artwork in `app/src/main/res/drawable/ic_buddha.png`.
