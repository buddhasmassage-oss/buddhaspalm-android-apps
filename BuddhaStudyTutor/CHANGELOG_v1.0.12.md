# BuddhaStudy Tutor v1.0.12

## Native admin screen capture and recording

- Adds a native Android screenshot bridge for the Tutor WebView.
- Saves screenshots as PNG to Pictures/BuddhaStudy Tutor on Android 10+.
- Adds Android MediaProjection screen recording with H.264 MP4 output.
- Saves recordings to Movies/BuddhaStudy Tutor on Android 10+.
- Adds JavaScript bridge methods used by the admin-only website Screenshot and Screen Record buttons.
- Keeps browser screen capture as the fallback outside the Android APK.
- Adds the Android foreground media-projection service and required Android 14+ permission.
