## App name
BuddhaStudy Tutor

## Package
net.buddhaspalm.tutor

## Short description
Massage therapy learning, quizzes, alerts and course downloads.

## Full description
BuddhaStudy Tutor is an Android learning companion for the BuddhaStudy online learning platform. It gives students a native starting point for opening their learning portal, receiving class notifications, keeping recent alerts in an in-app inbox, and managing course downloads.

Students can continue into the secure BuddhaStudy learning portal for lessons, course modules, quizzes, learning resources and progress-related activities. The Android app adds device-level functions around that learning experience, including Firebase push notifications, Android DownloadManager integration, native sharing, deep-link handling, file selection, camera/microphone permission handling where required by learning activities, and an offline retry screen.

BuddhaStudy Tutor also supports biometric/fingerprint login when enabled from the Tutor account. Biometric credentials are protected with Android Keystore and Android BiometricPrompt rather than storing an unprotected password in the app.

Native Android areas include the BuddhaStudy dashboard, Notification Inbox, Course Downloads and About screen. The learning portal itself is displayed in a dedicated Tutor activity with native Android navigation controls.

Official learning site: https://tutor.buddhaspalm.net/

## Reviewer note
BuddhaStudy Tutor is not a simple website launcher. The Android application provides a native dashboard, Firebase notification inbox, DownloadManager integration and download history, biometric authentication protected by Android Keystore, native sharing/deep links, file/media integration, offline recovery and native navigation around a dedicated learning portal. The embedded Tutor web content is the course-delivery portion of the application.
