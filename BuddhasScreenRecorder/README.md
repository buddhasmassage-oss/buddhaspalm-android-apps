# Buddhas Screen Recorder

Standalone Android screen recorder for https://screenrecord.buddhaspinas.com.

- Package: `net.buddhaspinas.screenrecorder`
- No SQL/MySQL database required by the Android app.
- Uses Android MediaProjection permission for full-screen capture.
- Saves MP4 video; microphone recording is optional.
- Draggable floating Buddha control provides Start, Pause, Resume, Stop & Save, Open Recorder, and Hide Ball actions.
- Existing BuddhasPalm Admin, Provider, Customer, Hub, Tutor, and School Android projects are not dependencies of this project.

Android intentionally requires the user to approve every new MediaProjection capture session. Apps or screens that prohibit capture may appear blank/black and are not bypassed by this app.
